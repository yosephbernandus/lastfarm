    A small technical story

    About Lastlight Farm

    This prototype separates perception, voice, and truth: Jev (or the local classifier) returns a constrained interpretation, an optional OpenAI dialogue generator voices the neighbor, and deterministic authored rules alone update the game. Mira and Asep remember supported interactions; neither provider can grant items, complete the promise, move you, or mutate relationships directly.

    Local prototype

    Babylon.js is bundled with this build. Jev and OpenAI adapters run only on the local server; their keys never enter browser code. If either provider is unavailable, deterministic interpretation and authored dialogue keep the story playable. Your save stays in this browser.
